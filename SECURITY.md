# Security Policy

## Supported Versions
Only the latest commit on the `main` branch is actively supported with security updates.

## Architecture & Privacy
The PAN-OS Unused Object Analyzer is a purely client-side application. 
* It does not connect to any backend server.
* It does not transmit telemetry, analytics, or configuration data.
* All `.xml` parsing and `set` command analysis occurs directly in the user's browser memory.

## Reporting a Vulnerability
If you discover a security vulnerability within the application code, please do not open a public issue. Instead, reach out privately to the repository owner to discuss a patch.
